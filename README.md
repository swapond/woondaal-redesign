# Woondaal King Kebab — Website Redesign

A minimal, editorial restaurant website for **Woondaal King Kebab**, Sylhet, Bangladesh.

Built with semantic HTML5, modern Tailwind CSS, Alpine.js reactive components, authentic Google Maps reviews, Foodpanda delivery integration, and WhatsApp table reservations and itemized cart ordering.

---

## 🍽️ Key Features

- **Hero Experience**: Minimalist hero banner with authentic culinary photography, call-to-action buttons for Menu and Location, and verified details.
- **Interactive Menu**: Categorized menu catalog (Kebabs, Chicken, Beef, Mutton, Vegetable, Rice, Naan, Soup, Salad), real-time search, responsive pricing in ৳ [BDT], and one-tap add to cart.
- **Cart & WhatsApp Ordering**: Slide-over cart drawer with quantity steppers, order type options (Dine-in, Takeaway, Delivery), customer details, and one-click redirect to WhatsApp (+880 1717-020505) with preformatted itemized orders.
- **Guest Experiences & Reviews**: Authentic testimonials from Sylhet locals, Google Local Guides, and overseas travelers with 5-star ratings.
- **Foodpanda Online Delivery**: Dedicated home-delivery callout card and direct ordering links with 4.5 ★ rating.
- **Visit & Contact**: Address, opening hours, one-click GET DIRECTIONS to Google Maps, and direct CHAT ON WHATSAPP.
- **Responsive & Accessible**: Touch-first mobile drawer, keyboard accessible modals, and schema.org JSON-LD restaurant metadata for SEO.

## 🚀 Local Development

No build tools required. Open index.html directly in any modern browser, or run a local static server:

`ash
# Python 3
python -m http.server 8080
`

Then visit http://localhost:8080.

## 🌐 Deploy to GitHub Pages

1. Push this repository to GitHub.
2. In GitHub, navigate to **Settings** > **Pages**.
3. Under **Build and deployment** > **Source**, choose **Deploy from a branch**.
4. Select branch **main** and folder **/(root)**, then click **Save**.
5. Your website will be live at https://<your-username>.github.io/<repo-name>/.
